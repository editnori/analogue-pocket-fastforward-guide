# Notice

This repo intentionally excludes binary payloads.

Do not add:

- BIOS files
- game ROMs
- save files
- generated `.rbf` files
- generated `.rbf_r` files
- full copied vendor/upstream source trees

The patches here are meant to be applied to the relevant upstream open-source
core checkouts by the person building the core.

The original cores remain under their original upstream licenses. This repo's
documentation and helper scripts are provided under the license in `LICENSE`.
